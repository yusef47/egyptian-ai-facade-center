# V113 Frontend Rebuild Design

## Status

Approved direction: rebuild the Vite + React frontend for the Egyptian AI Facade Center while preserving the existing V112.2 backend contract.

## Goals

- Rebuild the public experience around the Cairo Gold Studio visual language.
- Use full RTL Arabic presentation with Cairo typography.
- Add official Egyptian Engineers Syndicate branding and Egyptian flag treatment.
- Provide a national metrics section with four glassmorphism cards.
- Provide a focused AI Facade Studio with drag-and-drop upload, free-form prompt input, one restore action, and an output preview.
- Add a working Syndicate report download generated entirely in the browser.
- Preserve the existing OpenRouter/Vercel integration and avoid exposing credentials.

## Non-goals

- Do not modify `api/restore.ts`.
- Do not modify the `{ imageDataUrl, prompt }` request shape.
- Do not modify the `{ imageDataUrl }` success response shape.
- Do not add a new backend service or dependency unless the existing project cannot meet a requirement without it.

## Architecture

The application remains a Vite React TypeScript single-page app. The presentation is split into focused components:

- `Header`: official RTL branding, navigation, flag badge, and scroll anchors.
- `Hero`: title, subtitle, CTA, and supporting architectural context.
- `NationalMetrics`: four animated metric cards.
- `FacadeStudio`: upload/dropzone, prompt, restore action, loading/error states, and input/output imagery.
- `SyndicateReport`: report metadata and browser download action.
- `FooterStatus`: system status and version metadata.
- `App`: owns image, prompt, restore, status, and report state; retains the existing compression and fetch flow.

Existing `src/lib/image.ts` and `src/lib/openrouter.ts` remain reusable. The API route remains byte-for-byte unchanged.

## Interaction and data flow

1. A user selects or drops an image into the studio.
2. The existing `compressImage` helper converts it to a bounded JPEG data URL.
3. The user enters a free-form prompt.
4. The single `إرسال 🚀` action posts `{ imageDataUrl, prompt }` to `/api/restore`.
5. The frontend reads `data.imageDataUrl` and renders it in the output panel.
6. Errors are shown in an accessible live status region without clearing the input image.
7. The Syndicate report action creates a self-contained HTML document with the prompt, timestamps, status, and image references, then downloads it using a browser `Blob` URL.

## Visual system

- Background: deep obsidian `#0A0F1D` with architectural atmospheric gradients.
- Accent: Cairo gold `#C5A059`, brighter highlight `#E7C77E`.
- Surfaces: translucent dark panels with gold hairline borders and backdrop blur.
- Typography: Google Cairo with robust system fallback.
- Layout: RTL by default, wide editorial desktop composition, stacked mobile layout.
- Motion: restrained card entrance, hover lift, CTA glow, and output reveal; respect `prefers-reduced-motion`.
- Accessibility: semantic landmarks, explicit labels, visible focus states, keyboard-accessible dropzone, live status region, and non-color-only status indicators.

## Report behavior

The report is client-generated and downloaded as an HTML file. It includes:

- Egyptian Engineers Syndicate report title.
- Generation timestamp.
- Original prompt.
- Restoration status.
- Embedded input/output image data URLs when available.
- A note that the report was generated by the Egyptian Center AI Facade Studio.

The report action is disabled until a prompt or restoration session exists and presents a clear status when no data is available.
