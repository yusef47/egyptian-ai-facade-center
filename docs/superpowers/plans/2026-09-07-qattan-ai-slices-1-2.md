# Qattan AI Slices 1–2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans (recommended) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Migrate the clean V124 architectural prototype to a Qattan AI Next.js App Router product site and unified studio while preserving the tested facade, report, CAD, DXF, and OpenRouter behavior.

**Architecture:** Replace the Vite/Wouter runtime with a Next.js App Router runtime in the isolated `.worktrees/v115` checkout. A shared locale-aware marketing shell serves `/`, `/ar`, and `/en`; `/studio` renders a client-side workspace that composes the existing facade and CAD engines. The server-side restoration logic moves to `app/api/restore/route.ts` with a compatibility-preserving request contract, while tested domain utilities remain framework-independent under `client/src/lib` until the migration is verified.

**Tech Stack:** Next.js App Router, React 19, TypeScript, Tailwind CSS v4, Radix/shadcn primitives already present, Lucide React, Framer Motion where useful, Vitest, React Testing Library, Playwright Chromium smoke checks, OpenRouter Gemini image generation, Potrace-WASM, JSZip, Sharp.

## Global Constraints

- Work only in the clean isolated checkout `.worktrees/v115`; never touch the dirty root `master` checkout.
- Preserve Git linkage to `https://github.com/yusef47/egyptian-ai-facade-center.git` and the Vercel deployment workflow.
- Preserve `OPENROUTER_API_KEY` as a server-only environment variable; never place a real credential in source or client bundles.
- Preserve the request contract `{ imageDataUrl, prompt, mode? } -> { imageDataUrl }` for `/api/restore`.
- Preserve the verified AC1009 DXF serializer, V124 Potrace transform decoding, Zhang-Suen thinning, 4× crop preprocessing, local downloads, sequential ZIP processing, and existing report behavior.
- Do not copy mnml.ai source code, proprietary assets, logos, or protected visual files; use original Qattan AI copy, CSS, and generated/local visual treatments.
- Do not claim real authentication, persistence, credit debit, subscriptions, checkout, DWG generation, or independent model pipelines in Slices 1–2.
- Planned tool cards must be visibly marked as planned or remain non-submitting showcase links.
- Keep all public routes keyboard accessible, responsive at 390px and 1440px widths, and compatible with `dir="rtl"` and `dir="ltr"`.
- Run tests, typecheck, build, and `git diff --check` after each migration checkpoint that changes the build/runtime.
